# 抽样核对与交付

核对范围应随用户目的与图纸差异调整。常规新图接入先抽一个同柜体且资料较全的回路；新厂家、多模板或首次正式应用时增加不同布局的代表样本。以下是需要覆盖的风险类型，不要求每个任务都执行全部业务模块或运行全量测试。

## 先检查解析报告

读取 `summary.json`：

- `pages` / `page_summaries`：实际选页、图种、图号、对象/连接数、逐页 warnings；电气页为 OTHER 或零对象需要解释。
- `scope_check.unresolved_pages` / `blocked_connections`：哪些页或连接没有资格自动互证。不能因为没有崩溃就记为成功。
- `status_counts` / `conflict_count`：候选、规则通过、跨图验证与冲突数量；高 verified 占比不等于准确率。
- `functional_regions`：本次是否启用、失败页、待核对成员、公共线网；未启用则标明范围。
- `visualizations`：核对图与数据库属于同一 PDF、版本和选页；导出的全局图可能有节点数上限。

## 原图样本

| 样本类型 | 要观察的结果 |
| --- | --- |
| T/W 中一条明确连接 | 端点、设备接口、端子号、方向、原始来源一致，端点引用不误作本柜定义 |
| S 与 T/W 的同组对应 | 实际来源一致，状态与理由可解释；没有来源的图种明确缺失 |
| 同名不同柜体 | ID 与追踪路径隔离，外组来源不提升状态 |
| 接口点与端子同号 | 保留两个对象，以关系连接，不能合并成一个 |
| 十字交叉/邻近标签/设备外框 | 不仅凭交叉或距离确认；回到实际接点检查 |
| 短接排、分隔板、测试片 | 短接组可追踪、分隔不导通、条件状态明确；本图无此类附件则标“不适用” |
| 跨页延续或跨图册来源 | PDF 页码与 Sheet 分开；目标页、网标、组别和实际关系证据一致 |
| 候选/冲突与未找到路径 | 默认查线不混入未通过连接；未找到路径的结论限于当前数据 |
| 长表/多列/旋转或不同尺寸 | 下半页不漏 owner、不串列；原图框线和标签坐标没有偏移 |

用原始 PDF、`page_*_objects.png`、`page_*_topology.png`、`page_*_evidence.png` 交叉观察。若用户只问一条回路，就把核对限于该回路和相关页；不要为低影响查询修改源代码或重建全册。

## 可复制的新图接入记录

在本次输出目录写 `onboarding.md` 或用户要求的记录格式，至少包含：

```markdown
# 新图接入记录

- 图册/版本：
- 原始路径、SHA256、总页数：
- 解析工程路径、Python、依赖版本及配置/代码标识（有 Git 则记录提交）：
- 目标回路/柜体：
- 已清点页、已建库页、未覆盖页：
- 同组 S/T/W 页码映射与确认依据：
- 图例来源与模板差异：
- 建库/查询命令及输出目录：
- 对象/连接状态/冲突/未知分组摘要：

| 样本端点或路径 | 图号、Sheet、PDF页 | 原图观察 | 解析结果 | 结论/待补资料 |
| --- | --- | --- | --- | --- |

- 当前可用范围：
- 未解决问题与下一步：
- 源文件与数据库/图纸库版本的绑定依据；无数据库则填“仅原图识读”：
- 接入阶段：仅导航/已预检/试解析已核对/指定范围已建库，按真实产物填写：
- 业务版本状态（如适用）：仅建库/待复核/已审核/已发布，按真实状态填写。
```

空字段要填“未确定/未检查/不适用”及原因。样本标识从本次图纸取得；不要复制 ABB 示例标签作为新图事实。

如有业务人员确认的真值，分别记录检查了多少对象/连接、正确、误识别、漏识别、无法判定各多少。报告准确率/召回率时写明真值来源、分母、样本选择与未覆盖范围；算法 confidence、测试通过率和人工抽查比例不代替识别准确率。没有真值就只报告已完成的核对及具体例子。

交付链接指向实际 PDF、预检清单、SQLite、解析摘要、样本高亮和接入记录；只链接本次确实生成的文件。给出最短复用命令和当前限制。人工复核/发布需要相应人员真实执行，不替用户署名。

## 回路解释的核对

以用户具体问题为范围检查：位号是否属于当前柜、图示状态是否已确认、完整电流通路与回线是否成立、机械联动是否有依据、并联允许是否保留。闭锁/告警/跳闸分别追到实际执行元件；缺保护逻辑或定值时不报告动作门槛或必然跳闸。

解释来自原图观察而拓扑库未覆盖时，明确“原图可确认、数据库暂无支持”，不把口头推理写成已验证连接。软件高亮和标签框仅用于定位；不声称已完成设备内部动态仿真或现场状态确认。

对新图接入给出当前阶段、可用范围和缺口。预检通过只支持“可清点/可选页”，抽样核对只支持对应样本及已覆盖模板；若发现会影响正常查线的误并柜体、串列或缺失关键连接，应先限定使用范围并定位原因。

## 何时使用现有测试

普通换图优先实际样本与报告。若授权修改了解析或推理实现，再按变更选择现有测试，例如 `test_pdf_terminal_anchor.py`、`test_terminal_table.py`、`test_wiring.py`、`test_stw_scope.py`、`test_cross_drawing_projection.py`、`test_conductivity_policy.py`、`test_trusted_paths.py`。只有改动相关业务流程时才检查图纸库/人工补连等模块。测试应使用隔离输出与库目录，不向实际业务库运行创建账号、审核或发布的演示脚本。
