# 结合原图解释回路与设备动作

用于触点、分合闸、闭锁、保护及一次二次关系问答。无拓扑库也可用；数据库只提供可追溯接线线索，不能替代图示状态及机构动作的判断。

## 先建立当前图页的状态和对象

核对完整图号、柜体、设备表、厂家型号和图示基准状态，如“分闸、弹簧未储能”。常开/常闭是相对于约定基准状态的称呼；当前图纸画法、线圈得失电、机构位置和现场实际状态分开记录。

辅助触点的驱动源可能是断路器主轴、储能机构、闭锁电磁铁或操作按钮；沿机械标识、设备表及同设备引用确认。只因多个触点都叫 BGB1，不足以把不同柜的触点当成同一机构。

区分导线、机械联动虚线、功能框、元件归属和跨页引用。由电源和回线围成完整电流通路；有多电源、监视小电流、整流器或复合支路时分别追踪。明确动作前、条件满足、命令到来、机构动作、触点切换及复归，切换时间只有厂家/图纸有依据时才给数值。

## 组织解释

先直接回答用户的问题，再选必要信息说明：

- 当前对象：图号、Sheet、PDF 页码、柜体和实际位号。
- 动作链：用实际触点、线圈和机构串起原因与结果；保留有意义的并联分支。
- 状态变化：需要比较时用“初始/命令/完成/复归”的小表；不把所有触点说成一起闭合。
- 依据强度：分别标明原图明确、据接线推断、一般原理和缺资料无法确定。
- 缺口：说清哪项设备资料、对端页、保护配置或定值尚未取得，不让用户重复提供已存在的信息。

简单问答无需固定套用所有字段或生成报告。复杂逻辑可画简图，但说明其为功能概括，未展示的端子/支路仍以原图为准。

## 从一次设备到保护跳闸

先确认被保护对象和保护范围：进线、母线、变压器、电缆等。检查一次系统图中的 CT/VT、保护装置和断路器位置，避免把相邻设备故障一概归入同一断路器。

常见链条为：

`故障 -> CT/VT 或非电量传感器 -> 保护功能与逻辑 -> 跳闸出口触点 -> 控制电源与分闸线圈 -> 机构分闸 -> 位置反馈`

这些是待核对的功能类别，不是每个工程都已配置的保护：

| 异常或事件 | 应继续确认的资料 |
| --- | --- |
| 相间短路、较大过电流 | 速断/过流保护段、方向/闭锁条件、定值与延时、出口映射 |
| 接地故障 | 中性点接地方式、零序/方向接地保护、选线策略、告警或跳闸配置 |
| 长时间过负荷 | 过负荷/热保护定值、告警与跳闸阶段、运行方式 |
| 变压器内部故障 | 差动保护范围、瓦斯/压力等非电量保护、跳开哪些侧断路器 |
| 电压、频率异常 | 该功能是否投入，检测电压来源、延时和跳闸/闭锁对象 |
| 断路器拒动 | 失灵保护启动、判别、再跳与上级/相邻断路器后备出口 |

保护“启动”不等于“动作”，保护“动作”还须核对是否接入跳闸出口；出口发命令也不证明分闸线圈、控制电源、机构均已成功动作。判断保护范围与配合时，不凭一张控制图臆测整站切除顺序。

只有“主变保护屏分闸”这类出口标注时，可以追到分闸脱扣器；不能声称已查明差动、过流或非电量中的某一功能必然接到此出口。

## 合闸允许与闭锁

逐项确认联锁条件接到什么元件，以及动作极性：得电解锁、得电闭锁、失电脱扣不能混用。

1. 追踪闭锁线圈的独立电源通路与回线。
2. 将位置触点、装置 BO、气压及跨柜接线按串并联关系画成允许条件。
3. 找闭锁机构的辅助触点在合闸线圈通路中的位置。
4. 分开说明“允许合闸”和“收到合闸命令”，以及储能、已分位、防跳等其余条件。
5. 合闸后辅助触点断开而线圈退出可能是正常过程；结合机构保持方式解释，不据此判断断路器会自动分闸。

三工位开关可能具有正常运行、隔离、检修接地等不同允许组合。出现接地合位的并联支路时，要逐条查相邻开关的隔离条件，不能凭通用口号删去支路。

## 防跳与复归

防跳用于处理持续合闸命令下反复合分的风险。核对防跳继电器的起动、自保持、切断合闸及释放路径。是否必须撤销合闸命令、是否需手动复归或保护闭锁复归，取决于图中具体逻辑。不要把防跳解释成故障保护本身。

## 跨页查线

每段至少保留“本端设备:端子、对端设备:端子、线号/电缆号、图号/Sheet/格区”。先看标注规则，区分去向引用和本页实际端子定义。S 图解释功能，T/W 图核对端点与实际接线；不把跨柜同名设备或文字相邻当成导通。

证据不足时准确说出缺失项，如“缺保护出口配置”“缺该柜的对端页”“缺定值单”，并继续完成已可确认的部分。
