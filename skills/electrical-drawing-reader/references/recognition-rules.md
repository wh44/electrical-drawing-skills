# 对象、导通与证据规则

## 先读标识，再读连接

保留原始文字、bbox 和来源页；根据局部布局与图例解释，再规范化到结构化对象。规范化空格/全角分隔符不意味着可以删掉有意义的点号、加减号或接口层级。不同端子排、柜体、图纸版本中的同名标签独立。

| 原图表达示例 | 对象含义 | 不能作的推断 |
| --- | --- | --- |
| `X20:5` | 某柜体内 X20 排的第 5 号端子 | 与其他柜体 X20:5 自动等同 |
| `QAB:X20/5` | QAB 设备的 X20 接口第 5 点 | 直接改成 X20:5；它们需要显式连接 |
| `QBS1` | 设备实例标签 | 设备全部引脚属于同一导电网络 |
| `A1`、`A2`、`13`、`14` | 需结合所属设备和当前图例解释的 Pin | 仅凭常见编号确定现场触点/线圈状态 |
| `CN0003` 等 | 软件内部候选线网标识 | 原图有这根线号或已确认导通 |

端子表里的对端标识不一定定义了本柜端子；区分“本页端子排定义”和“对端引用”，不要仅由文字出现推断实际柜体归属。只知道 `X2` 时不能补造端子号；`X2:8` 不匹配 `X2:80`。`1/I/L`、`0/O` 或点号/冒号歧义应保留读法并核对。

## 分图种取得事实

**S 原理图：**识别元件、引脚、端子、网标和跨页标注，提取真实矢量线段并建立 CandidateNet，再绑定对象。纯十字交叉不自动合网；T 形接点与符号需按本页表达核对。不要把边框、表格线、虚线框或文字附近的几何当作确证。

**T 端子图：**以端子排、编号行、对端列及附件图例为主要结构，识别端子间或设备到端子的明确事实。空行、分隔符、测试片不作为普通端子。附件含义来自当前页或可确认适用的图例。

**W 接线图：**先确定设备标题和列范围，再逐行匹配设备侧接点与柜内端子。保留设备接口前缀。抽查相邻设备列、长表最底部及重复端子号，避免把引脚挂到最近但不属于该列的标题。

**跨页/跨图：**核对相同作用域、网标、Sheet/网格和实际目标页；链接只是定位线索。现流水线通过显式 W 映射向 S 的几何分支投影，再融合证据，并不代表所有跨页合并工具均已自动接入。是否支持某条跨页连接，以本次 `connections.json`/SQLite 的实际关系与证据为准。

## 互证状态的准确解释

当前流程为：解析 → 去重 → W→S 投影 → 证据融合 → 冲突检查 → 状态判定 → 持久化 → 功能区归属。

作用域不符合 `same_group_v1` 的自动连接保留 candidate。当前规则可仅凭同组 W 明确事实就给出 verified，或凭 T 表加另一来源给出 verified；**verified 并不必然说明 S/T/W 三类来源齐全**。分数阈值、先验和判定以当前 `config.py`、`evidence/verifier.py` 为准，属于本项目实现而非电气标准或统计校准概率。

每段连接至少可追溯到端点、关系、状态及实际存在的来源图号/图种/PDF 页码/Sheet、证据类型和坐标/原文。区分：

- 连接证据：本段关系在图中明确表达或有记录的推导。
- 端点来源：仅证明对象在哪里出现，不能算成该段连接的独立证据。
- 人工依据：确认/排除/修正/补连的人员、时间和原图依据，单独保留。

冲突先处理，不能通过聚合大量弱证据冲掉矛盾。缺失 S/T/W 某类来源时报告真实范围；短接附件等不适用的图种不要求凑齐。

## 关系与导通

以 `topology/conductivity_policy.py` 和当前追踪服务为执行依据：

| 关系 | 默认含义 |
| --- | --- |
| `PIN_TO_TERMINAL` / `DEVICE_POINT_TO_TERMINAL` / `TERMINAL_TO_TERMINAL` / `WIRE_CONNECTION` | 通过状态、作用域及其他追踪检查后参与电气追踪 |
| `BELONGS_TO_NET` / `CROSS_PAGE_CONTINUATION` | 仍需相应连接证据及状态检查；候选几何挂接不能自动升级 |
| `BRIDGED_TO` | 短接组导通，追踪层级成本为 0；不因多个相邻短接端子耗尽深度 |
| `SEPARATOR_BETWEEN` | 物理分隔，不导通 |
| `TEST_LINK_BETWEEN` | 条件连接，按明确状态/允许条件处理，不预设闭合 |
| `INTERNAL_CONTACT_PATH` / `COIL_INTERNAL_PATH` | 按明确状态/导通属性处理，不预设设备内部可通 |
| `HAS_*` / `INSTANCE_OF` / `MEMBER_OF_FUNCTION` | 结构或语义归属，不导通 |

从设备进入回路时选择实际 Pin/接点支路；整台设备汇总不能当作内部短接。功能区按空间和语义组织对象，公共骨干可属于多区；不能凭功能区框或归属边补画电线。

## 图像与答案

坐标沿用 PDF 页面坐标并核对旋转与页面尺寸；只改变 PNG 倍率不能修正解析坐标。标签框用于定位文字，不能证明接点与导线相接。

面向核对的导线高亮应沿保存的原图线段。某些旧 W/T 证据可视化会在同页端点中心之间画提示线，必须看图例和实现，不能把这种示意线当作原始导线。缺少几何时标明“仅端点定位/无法沿原线恢复”。

对“哪里接哪里”给出逐段端点与出处；对“上下游”说明当前是数据库关系方向或物理连通；对“未连通”区分漏选页、对象歧义、候选/冲突被排除和数据库暂无路径。不要据此声称现场断线、带电或安全可操作。
